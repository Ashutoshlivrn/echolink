✦ Core Capabilities

Everything You Need
to Share Audio

Built with modern Android audio APIs and WebRTC for the smoothest possible real-time streaming experience.

🎧
System Audio Capture
Captures any audio playing on your phone — YouTube, Spotify, games, calls — using Android's MediaProjection API with USAGE_MEDIA matching.
⚡
P2P WebRTC Pipeline
Peer-to-peer data channel with ordered delivery and intelligent jitter buffering. Falls back to WebSocket relay if NAT traversal fails.
📡
Zero Setup Signaling
Share a 6-character session code or QR code. Your friend joins in seconds — no IP addresses, no port-forwarding, no account required.
🔵
Bluetooth Earphone Ready
Streams directly into Bluetooth A2DP earphones on the receiver side. Plays via native AudioTrack on a dedicated high-priority thread.
📊
Real-Time Audio Monitor
Live RMS dBFS meter, peak amplitude, throughput (KB/s), and silence detection so you always know exactly what's being streamed.
🛡️
Host Approval Gate
Every connection requires explicit host approval. Reject unwanted listeners, kick participants mid-session — total control in your hands.

🚀 How It Works

Up and Running
in 4 Simple Steps

No accounts. No configuration. No hassle.

1
Host Opens App
Tap Start Sharing. The app captures your phone's audio and generates a unique 6-letter Session ID.
2
Share the Code
Send the Session ID or show the QR code to your friend — anywhere in the world via chat.
3
Friend Joins
Friend opens app, taps Join Session, enters the code or scans the QR. Host sees a connection request.
4
Stream Starts!
Host taps Accept. P2P WebRTC connects and audio streams live into the friend's Bluetooth earphones instantly.
